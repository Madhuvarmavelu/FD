# Football Director

A modern, single-player football club ownership simulator built with plain HTML, CSS and JavaScript.

## Play locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Start managing Northcastle United.

No build tools, package installation or API keys are required.

## Features
- Modern responsive boardroom dashboard
- Squad roster and player ratings
- Transfer market with affordability checks
- Club finances and sponsorship deals
- Facility upgrades
- Weekly match simulation and league table
- Local career save using browser localStorage

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `game.js` and this README to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site. Your URL will appear in the Pages settings.

## Notes
This is the first playable prototype. Match outcomes are simulated locally and saved in the browser. It does not yet include online accounts, cloud saves, real-world player data or a detailed tactical match engine.
